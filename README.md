# Qr_code**QR Code Generator | Python, QRCode Library, Pillow**

Developed a QR Code Generator application using Python that converts user-provided text, URLs, contact details, or other information into scannable QR codes. Implemented QR code generation, image customization, and file export functionality to create high-quality QR images for digital and print use. The project demonstrates practical knowledge of Python libraries, image processing, data encoding, and user-focused application development. QR codes are widely used for information sharing, payments, authentication, and digital marketing.

**Key Features:**

* Generate QR codes from text, URLs, and other user inputs.
* Save generated QR codes as image files (PNG/JPG).
* Simple and user-friendly interface.
* Fast and efficient QR code creation.
* Supports sharing of encoded information through scannable codes.

**Skills Demonstrated:** Python, QRCode Library, Pillow (PIL), Data Encoding, Image Processing, Automation, Software Development.
